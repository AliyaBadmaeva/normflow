# Нормализационные потоки: теоретические аспекты и их применение на практике

**Нормализующие потоки** (NFS) — генеративные модели, которые преобразуют простое базовое распределение в сложное целевое распределение с помощью серии обратимых преобразований. Основаны на концепции изменения переменных из теории вероятностей.
